# 로드러너 (LODE RUNNER)

브라우저에서 바로 하는 로드러너 클론. 단일 HTML, 설치·인터넷 불필요(첫 로딩 후 오프라인 동작).

**플레이:** https://won2070-commits.github.io/loderunner/

- 이동: 방향키 / WASD · 파기: Z(왼쪽) X(오른쪽) · 재시작: R
- 금괴를 전부 주우면 양끝 탈출 사다리가 열린다. 맨 위층 도달 시 통과.
- 벽돌을 파서 내려가거나 적을 빠뜨린다. 구멍이 메워질 때 적이 갇혀 있으면 제거(+400).
- 모바일은 화면 하단 터치패드. 홈 화면에 추가하면 전체화면 앱으로 실행된다.

로직 점검: `node test.cjs`
